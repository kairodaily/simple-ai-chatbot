## Simple AI Chatbot

A beginner-friendly AI chatbot built with Python.

## Features
- Simple conversation system
- Easy to understand code
- Works with OpenAI / Grok / Claude API

## How to use
1. Install library: `pip install openai`
2. Open the file `chatbot.py`
3. Add your API key
4. Run the file
